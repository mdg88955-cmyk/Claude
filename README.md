# ATHLESIO — Shopify Brand Launch Package

Dieses Repository ist das Vorbereitungspaket für den ATHLESIO Shopify-Store
(Zielmärkte: Deutschland & Österreich, Domain: `athlesio.at`). Es wurde
erstellt, **bevor** die eigentlichen Shopify-, Hostinger- und Gmail-Konten
existierten — Ziel ist, dass jeder Schritt sofort umgesetzt werden kann,
sobald diese Konten stehen.

## Warum kein "fertig deployter" Shop?

Ich habe (noch) keinen Zugriff auf ein Shopify-Konto, Hostinger-Konto oder
eine Domain — die musst du erst anlegen. Sobald du mir Zugang gibst (siehe
`docs/shop-setup-guide.md`, Abschnitt "Kontrolle übergeben"), kann ich die
Inhalte aus diesem Repo direkt im Store anlegen, statt dass du sie manuell
kopierst.

## Inhalt

| Datei | Zweck |
|---|---|
| `docs/brand-strategy.md` | Positionierung, Wettbewerbsanalyse (atletica.de, neolymp.com), Farben, Ton, Maskottchen-Konzept |
| `docs/supplier-shortlist.md` | Recherchierte EU-Lieferanten/Fulfillment-Kandidaten für die 3 Hero-Produkte |
| `docs/shop-setup-guide.md` | Schritt-für-Schritt Shopify-Setup, Navigation, Apps, Domain-Verbindung |
| `content/products/` | Fertige deutsche Produkttexte (SEO-Titel, Beschreibung, Bullet-Points, Richtpreis) für PowerBand Set, FlexBoard, StepCore |
| `content/pages/` | Über-uns, Versand & Lieferzeit, Kontakt |
| `mascot/leo-mascot.md` | LEO-Maskottchen-Konzept + generierte Bild-/Video-Assets (Higgsfield) |

## Die 3 Hero-Produkte

1. **ATHLESIO PowerBand Set** — Premium-Widerstandsband-Set (Hero-Produkt)
2. **ATHLESIO FlexBoard** — faltbares Pilates-Board (visuelles Upgrade)
3. **ATHLESIO StepCore** — mechanischer Mini-Stepper (Cardio-Erweiterung)

## Nächste Schritte (für dich)

1. Domain `athlesio.at` bei Hostinger kaufen.
2. Shopify-Konto anlegen.
3. Mir Zugang geben: Staff-Account in Shopify **oder** Admin-API-Token
   einer Custom App (Details in `docs/shop-setup-guide.md`).
4. Ich richte darauf Theme-Branding, Navigation, Collections und die 3
   Produkte aus diesem Repo direkt im Store ein und binde die Domain an.
5. Lieferant aus `docs/supplier-shortlist.md` final auswählen und Muster
   bestellen, um echte Lieferzeiten/Qualität zu validieren, bevor Ads
   geschaltet werden.

## Offene Platzhalter, die du noch ausfüllen musst

- Firmendaten fürs Impressum (Anschrift, ggf. Firmenbuchnummer, USt-IdNr.)
- Finaler Lieferant je Produkt inkl. Einkaufspreis → finale Verkaufspreise
- Instagram/TikTok-Links für den Personal-Brand-Aufbau
- Ggf. konkrete technische Daten der Produkte (Belastbarkeit FlexBoard,
  Trainingscomputer-Funktionen StepCore) je nach gewähltem Lieferanten
